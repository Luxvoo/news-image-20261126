# News Image — 26 November 2026

Entry for the make.fun bounty: https://make.fun/bounty/news-image-20261126

The program writes a single 1024x1024 PNG summarizing world news for
Thursday 26 November 2026. It runs offline and copies the bundled image
asset to `/output/entry.png`, so repeated runs produce identical bytes.

Headlines cover the Kuwait drone attack, the next ECB president, Congo's
Ebola outbreak, Ukraine's power grid, Guinea-Bissau elections, and Nvidia
server shipments. Source names are printed on the image.
